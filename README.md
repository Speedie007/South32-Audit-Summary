# South32 Audit Summary

Working repository for development of a consolidated South32 audit summary report.

## Repository Structure

```text
South32-Audit-Summary/
├── AGENTS.md                       # Repository-wide working instructions
├── README.md                       # Repository orientation
├── CompletedReports/               # Completed/final source reports
└── SummaryReport/
    ├── SummaryReportContext.md     # Living context for the summary-report exercise
    └── Notes/                      # Working notes and supporting development material
```

## Current Source Material

`CompletedReports/` currently contains five completed PDF reports covering:

- Main Shaft Head Sheaves

- Upper Gantry Guide Sheaves

- July 2026 Spillage Audit Report

## Working Convention

Read `AGENTS.md` for repository-wide instructions and `SummaryReport/SummaryReportContext.md` for the current report-development context before making substantive changes.

Completed reports are treated as source/reference records and should remain unchanged unless explicitly instructed otherwise.
