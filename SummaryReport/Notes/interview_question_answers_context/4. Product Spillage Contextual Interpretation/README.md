# 4. Product Spillage Contextual Interpretation

## Purpose

This folder preserves the detailed historical interview context for the **Product Spillage** section-specific interpretation round.

The round will establish how the completed Combined-Product Spillage Audit should be interpreted and represented in the South32 Wessels Mine high-level summary report.

Each interview question will have its own Markdown file containing:

1. the exact question asked;
2. the user's answer as provided;
3. the contextual interpretation of that answer;
4. the contextual significance for the Product Spillage section of the summary report.

## Working Rule

The original answer must be preserved verbatim. Later refinements should be added as refinements or superseding context rather than replacing the historical response.

The user's initial overview of the philosophy, structure, intent and desired summary-report treatment should be received before targeted interview questions are introduced.

At the end of this round, accepted conclusions will be consolidated into a dedicated Product Spillage contextual interpretation file in `SummaryReport/Notes/`, with references back to the individual question records.
