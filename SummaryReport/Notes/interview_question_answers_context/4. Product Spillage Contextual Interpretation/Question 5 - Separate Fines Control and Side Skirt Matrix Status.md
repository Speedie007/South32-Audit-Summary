## Contextual Interpretation

The management-facing inspection matrix should contain **two separate remedial-status fields** so the system-wide fines-control programme and the localized coarse-product side-containment programme remain clearly distinguishable.

### Accepted Matrix Fields

The current baseline matrix columns are:

1. **Inspected section / conveyor**
2. **Underground or surface**
3. **Dominant spillage type observed**
4. **Principal mechanism / concern**
5. **Primary remedial philosophy**
6. **Fines / cleaner-control status**
7. **Side-skirt status**
8. **Detailed-report reference**

### Fines / Cleaner-Control Status — Baseline Categories

Use categories such as:

- **Pilot / reference location**
- **Upgrade required**
- **Systematic rollout applicable**
- **Geometry-specific exception / local design required**
- **Not presently applicable**

The exact labels may be refined during matrix drafting if a clearer management presentation emerges.

### Side-Skirt Status — Baseline Categories

Use categories such as:

- **Explicitly recommended / early implementation**
- **Report-supported future applicability**
- **Candidate for site review**
- **Monitor / review**
- **Not presently indicated**

## Contextual Significance

Keeping the two status fields separate prevents the matrix from implying that side skirting is the dominant or universal remedial programme.

The matrix should make clear that:

- the **fines / cleaner-and-containment programme** is the principal system-wide rollout philosophy across relevant conveyor head/discharge locations; while
- the **side-skirt / spill-seal programme** is selective and mechanism-specific, applied where coarse/mixed-product lateral containment is required.

The matrix structure remains a baseline and may be refined later during drafting if presentation or management readability can be improved without losing the accepted technical distinction.
