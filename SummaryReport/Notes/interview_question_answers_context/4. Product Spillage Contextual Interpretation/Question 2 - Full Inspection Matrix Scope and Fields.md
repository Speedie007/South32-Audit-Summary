## Contextual Interpretation

The Product Spillage summary should include a **complete management-facing inspection matrix** covering all inspected conveyor/process sections, not only the locations where a side-skirt solution is already proposed.

The matrix should provide system visibility and show why a side-skirt/spill-seal concept is, or is not, relevant at each location.

## Accepted Matrix Fields

Retain the following columns as the baseline:

1. **Inspected section / conveyor**
2. **Underground or surface**
3. **Dominant spillage type observed**
4. **Principal mechanism / concern**
5. **Primary remedial philosophy**
6. **Side-skirt status**
   - recommended;
   - potential future applicability;
   - monitor / review;
   - not presently indicated.
7. **Detailed-report reference**

## Contextual Significance

The matrix is intended to:

- show management the full inspected conveyor/process population;
- distinguish system-wide fines issues from localized coarse-product loss;
- identify where side skirting is directly recommended versus only potentially applicable;
- avoid implying universal side-skirt installation;
- provide a concise bridge from the summary report back to the detailed spillage report;
- support later maintenance/project planning without replacing the source report.

The side-skirt status should be evidence-based and mechanism-specific. Where the source report does not support a firm recommendation, the matrix should use a qualified status such as **potential future applicability** or **monitor / review** rather than infer a requirement.
