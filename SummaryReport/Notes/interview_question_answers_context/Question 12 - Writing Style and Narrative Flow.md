## Contextual Interpretation

The proposed six-stage narrative flow is accepted as the baseline structure for the summary report and for the section-specific technical narratives where appropriate.

### Baseline Narrative Flow

1. **What was inspected**
2. **What the collective findings indicate**
3. **What that means operationally/technically**
4. **What remedial philosophy follows from that**
5. **What should happen first, next, or be verified before scaling**
6. **What the broader implications are going forward**

This flow supports the intended function of the summary report as an interpretive bridge between detailed inspection findings and management-level understanding.

### Writing Style

The report should be:

- **formal and professional**;
- written in **plain English where possible**;
- **technically precise without being overly academic**;
- primarily **prose-led**;
- supported by **selective tables or figures only where they genuinely clarify the message**.

The writing should prioritize clarity, technical credibility, and logical progression over dense technical presentation.

## Contextual Significance

The report should read as a coherent technical narrative rather than as a collection of inspection notes, data extracts, or isolated recommendations.

The six-stage flow should act as the default narrative logic, while still allowing variation where a particular section requires a different sequence for clarity.
