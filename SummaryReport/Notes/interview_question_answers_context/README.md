# Interview Question and Answer Context Index

## Purpose

This folder preserves the detailed historical record of the summary-report interview process.

Each interview question has its own context file containing:

1. the exact question asked;
2. the user's answer as provided;
3. the contextual interpretation derived from that answer;
4. the contextual significance for the developing report framework.

This detailed record is maintained to minimize contextual drift and prevent important decisions or nuances from being lost during later consolidation.

## Standard Working Procedure

- Create one context file for every interview question.
- Record unanswered questions as **Pending answer** rather than omitting them.
- Do not overwrite the historical user answer when later interpretation changes.
- If later answers refine or supersede an earlier interpretation, preserve the original history and note the later refinement.
- At the end of each interview round, create a consolidated round context file that synthesizes the accepted conclusions from that round.
- The round consolidation should reference the individual question files from which each conclusion was derived.
- The consolidated round files become progressively higher-level context records, while the individual files remain the authoritative interview history.
- The main `SummaryReportContextualFramework.md` should contain the current accepted framework and reference the detailed/intermediate context where appropriate.
