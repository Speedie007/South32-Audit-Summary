# Question 11 - Reader Familiarity and Source Report Referencing

- **Question:** 11
- **Status:** Answered

## Question Asked

> What should the report assume about the reader’s knowledge of the source reports?
>
> Should the summary report be written so that:
>
> - it can stand largely on its own for a reader who has **not** read the detailed reports;
> - it assumes the reader has access to the detailed reports but may not have read them;
> - or it assumes the reader is already familiar with the detailed reports?
>
> Related to that, when a section refers back to a detailed report, do you want references to be:
>
> - fairly explicit, for example naming the relevant report and section;
> - lighter, for example “refer to the detailed Cable Belt Main Drive Sheave report”;
> - or only used where necessary so the narrative remains clean?
>
> This will affect how much background explanation we need to carry into the final summary.

## User Answer

> for What should the report assume about the reader’s knowledge of the source reports? It should be a combination of it assumes the reader has access to the detailed reports but may not have read them; and/or it assumes the reader is already familiar with the detailed reports. For when a section refers back to a detailed report, Genreally only used where necessary so the narrative remains clean, but if there is specific detail that requires excplict clarification for that we can use a combination of fairly explicit, naming the relevant report and section; or lighter, for example “refer to the detailed Cable Belt Main Drive Sheave report” when required.

## Contextual Interpretation

The summary report should assume that the intended reader:

- has access to the detailed source reports;
- may or may not have read them in full;
- may already be familiar with some or all of them.

The summary therefore does not need to reproduce the detailed technical content, but it must still contain enough contextual explanation for the high-level narrative and interpretation to remain understandable.

### Source Report Referencing

References back to the detailed reports should generally be used only where necessary so that the summary remains readable and uncluttered.

Two levels of reference may be used:

1. **Light reference**
   - Example: “Refer to the detailed Cable Belt Main Drive Sheave report.”
   - Use where the purpose is simply to direct the reader to supporting detail.

2. **Explicit reference**
   - Name the relevant report and, where useful, the relevant section.
   - Use where a specific finding, technical detail, qualification, or traceability point requires precise clarification.

The report should not overload the narrative with constant report citations where they do not materially improve understanding.

## Contextual Significance

The summary report should function as an interpretive document that is understandable without requiring the reader to reread every detailed report, while still relying on those reports as the underlying evidence base.

The preferred reference style is **minimal but traceable**:
- keep the main narrative clean;
- refer back to source reports when useful;
- use explicit report/section references only where specific clarification or evidentiary traceability is needed.
